# Зомби Ферма — неофициальный справочник

Это единый рабочий репозиторий публичного сайта: https://stillsickstillsick.github.io/zombie-farm-guide-site/ . GitHub Pages публикует ветку `main` непосредственно из этого репозитория, без второго push и без копирующего workflow.

## Сборка и проверка

Канонические данные находятся в `data/*.json`, оригинальные локальные изображения — в `img/`. После редактирования данных выполните:

```sh
python3 scripts/compact_canonical_json.py
python3 scripts/build.py
python3 scripts/check_site.py
```

Затем добавьте изменённые данные и сгенерированные страницы в один коммит и отправьте его в `main`. Для обычной сборки достаточно Python 3; отдельные исследовательские импортёры могут требовать дополнительные пакеты и внешние кэши. Открывать `index.html` можно локально, сайт не требует сетевых ресурсов для отображения.

## Не публиковать закрытые материалы

`research/` намеренно исключён из этого публичного репозитория через `.gitignore`. В него нельзя добавлять приватные исследования, исходники и фотографии Острова Фанатов. Прежний приватный репозиторий является отдельным хранилищем исследований, не частью процесса публикации. Исторический импортёр, способный создать карточку Острова Фанатов, намеренно не перенесён.

Исследовательские источники и исторические версии могут содержать противоречия; нельзя представлять реконструкцию расположения объектов как подтверждённый оригинал. Права на игровой графический материал требуют проверки.
